01. PHASE OBJECTIVE
================================================================

Deploy the previously captured Windows 11 Enterprise
reference image onto a separate virtual workstation.

The deployment process included:

- Provisioning a new Windows 11 virtual workstation
- Transferring the captured-image storage disk
- Booting the target workstation into Windows PE
- Preparing a UEFI/GPT partition layout
- Applying the captured Windows image using DISM
- Creating boot files using BCDBoot
- Configuring a dedicated Windows Recovery partition
- Completing Windows Out-of-Box Experience
- Establishing a local administrator account
- Assigning a standardized computer name
- Verifying inherited deployment configuration files
- Preserving a post-deployment baseline snapshot

All work was performed in a simulated, non-production
environment using virtual machines.

07. WINDOWS IMAGE APPLICATION
================================================================

The captured WIM was applied from the image storage
disk to the newly prepared Windows partition.

Image Source:

C:\Images\NS-W11-ENT-BASE-01.wim

Image Index:
1

Target Windows Partition:
W:\

DISM Command:

Dism /Apply-Image /ImageFile:"C:\Images\NS-W11-ENT-BASE-01.wim" /Index:1 /ApplyDir:W:\ /CheckIntegrity /Verify /ScratchDir:C:\Scratch /LogPath:C:\Images\Apply_Image.log

The capture storage disk also provided a dedicated
DISM scratch directory.

An initial command failed with Error 87 due to a
missing space between command parameters.

The syntax was corrected without repartitioning
the target disk or modifying the WIM.

The corrected command completed successfully.

Final DISM Result:

Applying image
100.0%

The operation completed successfully.

RESULT: PASSED

09. WINDOWS RECOVERY IMAGE PREPARATION
================================================================

The deployed Windows installation contained:

W:\Windows\System32\Recovery\Winre.wim

Verified File Size:
796,822,851 bytes

The recovery image was identified as a hidden and
system-protected file.

A recovery directory was created:

R:\Recovery\WindowsRE

Initial file-copy attempts encountered command
parsing errors and difficulty accessing the
hidden system file.

The file attributes were inspected using:

attrib W:\Windows\System32\Recovery\Winre.wim

The final successful copy used:

xcopy /h /y W:\Windows\System32\Recovery\Winre.wim R:\Recovery\WindowsRE

Result:

1 File(s) copied

The destination file was verified.

Verified Destination Size:
796,822,851 bytes

18. DEPLOYMENT TROUBLESHOOTING SUMMARY
================================================================

ISSUE 01:
DISM Parameter Error

Observed Error:
87 - The parameter is incorrect.

Cause:
Missing space between DISM command parameters.

Resolution:
Corrected command syntax and repeated image application.

Outcome:
DISM completed at 100%.

---------------------------------------------------------------

ISSUE 02:
Recovery Image Copy Parsing Error

Observed Error:
Parse Error

Cause:
Invalid trailing quotation mark in the XCOPY command.

Resolution:
Removed the incorrect quotation mark.

---------------------------------------------------------------

ISSUE 03:
Recovery Image File Access

Observed Error:
The system cannot find the file specified.

Finding:
Winre.wim had hidden and system file attributes.

Resolution:
Used XCOPY with the /h parameter.

Outcome:
Recovery image successfully copied and verified.

---------------------------------------------------------------

ISSUE 04:
Offline Windows Recovery Status

Observed Status:
Disabled

Finding:
REAgentC successfully registered the recovery
directory, but offline status verification did not
confirm Windows RE was enabled.

Next Action:
Validate and, if necessary, enable Windows RE
during Phase 5.

PENDING POST-DEPLOYMENT VALIDATION
