08. BITLOCKER CONFIGURATION INVESTIGATION
================================================================

INCIDENT ID: SEC-001
CATEGORY: Endpoint Security Configuration
STATUS: RESOLVED FOR LAB ENVIRONMENT

INITIAL OBSERVATION:

The deployed workstation began encrypting its
Windows system partition automatically.

Observed Encryption State:

Conversion Status: Encryption in Progress
Percentage Encrypted: 82.6%, later 82.7%
Encryption Method: XTS-AES 128
Protection Status: Protection Off
Key Protectors: None Found

ASSESSMENT:

Encryption was underway, but the drive was not
protected by configured BitLocker key protectors.

This was not an acceptable completed encryption
configuration for a managed production endpoint.

The precise trigger for automatic encryption
was not independently established.

CORRECTIVE ACTION:

The following command was executed:

manage-bde -off C:

This initiated decryption of the Windows volume.

FINAL VERIFICATION:

Conversion Status: Fully Decrypted
Percentage Encrypted: 0.0%
Encryption Method: None
Protection Status: Protection Off
Lock Status: Unlocked
Key Protectors: None Found

OUTCOME:

The unexpected encryption process was stopped
and the system returned to a fully decrypted state.

NOTE:

For a production enterprise workstation,
BitLocker should be configured according to
organizational security policy, with appropriate
key protectors and securely managed recovery keys.

The lab remediation does not represent a
production-ready encryption configuration.

RESULT: RESOLVED
