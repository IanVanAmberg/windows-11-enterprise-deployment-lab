13. INSTALLATION TROUBLESHOOTING
================================================================

OBSERVATION ID: SETUP-002
CATEGORY: Virtual Workstation Boot

SYMPTOM:

The initial virtual machine startup displayed a
message requesting a keypress to boot from the
installation ISO.

After the prompt timed out, the VM reported that
no bootable operating system was found.

CAUSE:

Windows was not yet installed on the virtual disk,
and the installation ISO boot prompt had timed out.

CORRECTIVE ACTION:

The VM was restarted and the installation ISO
boot prompt was acknowledged using the keyboard.

VALIDATION:

Windows Setup loaded successfully.
Windows installation completed.
